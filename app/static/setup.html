Govee Cloud API

…

How to get your API key:

  1. Open the Govee Home app on your phone
  2. Go to My Profile → Settings
  3. Tap "Apply for API Key"
  4. Fill in the short form — the key arrives by email, usually within minutes

Qingping

…

How to get your credentials:

  1. Register at developer.qingping.co (same account as your Qingping+ app)
  2. Click your email in the top-right corner
  3. Go to "Access Management"
  4. Copy your App Key and App Secret

ℹ Only devices bound in the Qingping+ app will appear. BLE-only sensors (temp/humidity) only upload when the phone app or a Qingping gateway syncs them.

Govee Live Energy optional

…

⚠ This uses Govee's unofficial IoT channel (the same one the phone app uses) to get live watts/volts/amps from energy-monitoring plugs like the H5086. It may break if Govee changes their backend.

The official Govee API (above) does not expose energy data — this is the only way to get it.

Setup:

  1. Enter the email and password you use in the Govee Home app
  2. Click "Save & Send Code" — Govee will email you a verification code
  3. Enter the code below and click "Verify"

Energy Cost

Set your electricity rates to see cost estimates on the energy chart. Peak hours apply on weekdays only; all other times use the off-peak rate.

Advanced

Polling intervals control how often each integration checks for new data. Lower values mean fresher data but more API calls.
